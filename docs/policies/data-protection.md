# Data Protection Policy

Kestrel Bridge Finance is a fictional company. This policy is synthetic demo content.

## Scope

This policy covers all personal data about customers, colleagues and suppliers, in any format.

## Handling personal data

- Only access personal data you need for your role.
- Never send customer data to a personal email address or store it on personal devices.
- USB memory sticks are blocked on company devices. Use approved SharePoint sites to share files.
- Printed documents containing personal data must be shredded using the confidential waste bins.

## Subject access requests

- Anyone can ask for a copy of the personal data we hold about them. This is a data subject access request (DSAR).
- Forward any DSAR to the Data Protection Officer within 1 working day of receiving it, whatever channel it came through.
- We must respond within one calendar month of receipt. The DPO decides whether an extension is allowed.

## Data breaches

- A data breach includes lost or stolen devices, emails sent to the wrong person, or unauthorised access to data.
- Report any suspected breach to the IT Service Desk and the Data Protection Officer immediately, and no later than 1 hour after you discover it.
- Do not try to investigate or fix the breach yourself.
- The DPO decides whether the breach must be reported to the regulator, which must happen within 72 hours where required.

## Retention

Customer records are kept for 6 years after the end of the relationship, then securely deleted.
